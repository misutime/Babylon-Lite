# 包体积后续优化结果

本整合变更基于合入 PR #736 和 #737 之后的 master `adca50f3`。其中仅包含保留的包体积优化工作，不再包含矩阵变更的另一份副本。测量仅统计运行时加载的 JavaScript，沿用原有的 raw/gzip 统计口径和未修改的场景体积上限。历史矩阵 CPU 测量数据不再作为这些变更的证据。

## 相对当前 master 的最终合并结果

保留的变更集包括：片段自持的 PBR 常量、修正后的存储纹理访问描述符（storage-texture access descriptors）、合并后的 Node 管线描述符，以及按需启用的图特定（graph-specific）懒加载块加载器。目前 master 已独立合入单次着色器绑定分发（single shader-binding dispatch），因此其早期的体积节省不再计入本 PR。较大幅度的体积收益需要为固定图选择其所用块；默认加载器仍继续支持任意图，无需额外显式启用。

## 保留项：小幅收益

Clearcoat 存在标志以及 sheen 纹理/反照率缩放常量现已移至各自所属的懒加载片段中，共享账本中保留的位号保持不变。单独测量时，此项在四个 PBR 对照场景中可节省 45-52 raw 字节与 9-35 gzip 字节；两个 Standard 对照场景与原始基线按字节完全一致。

着色器组合器（shader composer）现在对每种绑定类型仅处理一次，即可同时生成其 WebGPU 描述符与 WGSL 声明，消除了重复分发且不引入中间对象。绑定顺序、组号、阶段可见性与着色器文本均保持不变。同一路径还修复了一个潜在的存储纹理错误：WGSL 的 `read`/`write`/`read_write` 必须映射为 WebGPU 的 `read-only`/`write-only`/`read-write`。相对重新捕获的仅含标志基线，该变更在每个被测场景中又节省了 135-146 raw 字节与 7-40 gzip 字节。

## 已拒绝并恢复

WGSL 别名归一化最初被保留，但随后破坏了一个现有的几何输出变体用例：`composePbrGeometryShader` 依赖原始 PBR 返回语句的拼写形式。全部三处模板变更及其架构说明均已回退；该用例重新通过。旧的别名捕获数据仅为历史证据，**并非已接受的最终结果**。

光源克隆隔离（light-clone isolation）在非克隆场景中节省了字节，但增大了克隆对照场景的体积。三个变体均被拒绝：最大 gzip 回归分别为 48、10 和 19 字节。所有原型源码变更已全部恢复；未保留任何针对压缩的专项调优。

## 保留项：Node 管线描述符整合

通用 NME 编译器在 scene62 中贡献了 5,822 字节的归属体积。两种 caster-output 提取变体均被拒绝并恢复：第一种使 caster 对照场景增加了 407-417 gzip 字节；第二种尽管在非 caster 对照场景中节省了 531-763 gzip 字节，但仍使 caster 对照场景增加了 75-91 字节。

保留的变更保持输出所有权与懒加载边界不变：直接一次性构造 color/depth/ESM 管线描述符，而不再先创建默认描述符再替换两个着色器阶段并伴随第二个深度描述符。几何体保留其现有回调。着色器文本、绑定顺序、alpha/深度/剔除行为以及同步重建均保持不变。

## 保留项：图特定注册表

按需启用的加载器接收一组固定的、从根包导出的 `NodeMaterialBlock` 描述符列表。每个描述符携带其类名及内部懒加载器；公共选择 API 中不添加任何 GPU 句柄。选择所需块会移除通用注册表，但仍保留懒加载导入，包括针对未打包的包使用方。动态/默认加载器保持不变。缺失与重复的选择会显式拒绝。

块目录由现有注册表生成。图加载器生成器会解析出与默认加载器相同的 core/full PBR 选择结果，包括未连接的序列化块、副作用块及几何终端节点。生成的加载器属于常规的计数运行时模块，绝非被排除的 `*-nme.ts` 数据载荷。简单纹理图已超过 1 KiB gzip 的保留目标。完整 NME、循环图与几何图体积也有所缩小。在独立实验期间，用户明确接受了 scene2 最多 +4 gzip 字节及 scene141 最多 +3 raw 字节的对照漂移；所有上限均未修改。后续的 master 集成及其单独的明确批准情况已记录在上方的最终合并结果中。

首个即时加载（eager）目录因超出场景上限而被拒绝。逐块静态变体为打包工具使用方节省了更多字节，但会将每个块实现连接到未打包的根导入中。该方案已被懒加载设计取代，未予合入。目前未保留任何即时加载选择器模块。

图预编译（graph precompilation）经单独评估后已推迟：Map、特性回调、实时输入及几何体重新发射需要专门的表示形式与 API。它并非注册表体积收益所必需，也不包含在本 PR 中。
