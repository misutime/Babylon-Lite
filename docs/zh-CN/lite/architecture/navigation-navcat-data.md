# Navcat 数据、回调与生命周期

## 所有权与 JSON

工厂函数接受带版本号的 JSON 资产：`{format:"babylon-lite-navcat",formatVersion:1,sdkVersion:"0.4.1",navMesh:...}`。内嵌的 Navcat 网格采用右手（RH）坐标系，在解析后由管理器独占。生成与导出均产出自该信封格式（含已添加的连接）。若遇到原始 SDK JSON、未知格式版本或 SDK 版本不匹配，会以明确诊断信息拒绝；升级 SDK 时请重新生成资产。

在发布前，会校验对象根节点、有限的三分量原点、正数的图块（tile）尺寸、节点/链接数组、图块/映射/连接记录以及索引池对象。图块条目需要数值坐标/细节数组、多边形与细节网格数组、BV 树数据以及多边形节点数组。依据锁定的 SDK 结构校验多边形顶点/邻接数组及边界、细节范围/三角形、BV 节点、已分配的节点/链接引用（包括打包的类型/索引/所有者序列号）与有界多边形/链接边、连接定义/附着关系以及池空闲/分配/计数器一致性和映射条目。不执行任何有损重烘焙。对于畸形根节点抛出 `Invalid Navcat JSON`，并在解析/校验失败时保留当前网格。

私有管理器状态包括：可空的 SDK 网格与运行时 API、拷贝后的回调选项、缓存的 SDK 查询过滤器及校验后的半包围尺寸元组、已销毁标志、单调递增的图修订版本以及网格版本计数器。默认半包围尺寸为 `{x:1,y:2,z:1}`。所有位置均为有限值；所有半包围尺寸均为有限且非负。flags 为 16 位无符号整数；area 为非负整数。

## 生命周期

- 工厂在导入 SDK 前先校验/拷贝选项，解析 JSON，然后发布单个已初始化的句柄。
- 替换操作会先完成完整的解析与校验。原子性发布会替换所拥有的网格，并递增图修订版本与网格版本；过滤器与半包围尺寸得以保留。旧网格/缓存/连接不再被管理器持有。
- 连接的添加/移除会递增图修订版本。连接句柄不持有网格；在发生替换或池 ID 复用后，网格版本与 SDK 序列号会守护移除操作。
- 销毁是同步且幂等的：设置已销毁标志、递增修订版本/版本号、清空网格/API/过滤器/半包围尺寸。SDK 网格无需显式 WASM destroy。同时清除缓存的查询过滤器/半包围尺寸引用。管理器上不存在任何钩子、群体（crowd）、调试对象、定时器或 Worker。
- 除重复销毁外，每个 API 都会检查存活状态。销毁后的同步调用会抛出 `Navcat manager is disposed`。挂起的异步可选操作会在导入后检查网格版本，因此替换/销毁操作绝不会使旧网格死灰复燃。
- location 操作会拒绝错误的所有者、过期的图修订版本以及无效/非多边形节点引用。销毁后既有快照仍归调用方所有，但无法再用于查询管理器。

## 过滤器

在赋值时拷贝过滤器的选项对象，同时保留回调标识；绝不修改共享的 SDK 默认过滤器。仅在创建或设置过滤器时构建/缓存 SDK 过滤器；未提供覆写时直接使用共享的 SDK 默认过滤器而不做修改。默认行为包含 include flags `0xffff`、exclude flags 0、其余全部通过以及欧几里得遍历代价。include/exclude 位会在可选的 pass 回调之前应用。

每个回调借用由可复用适配器临时对象支持的只读左手系（LH）向量/节点视图，绝非直接暴露 SDK 对象。其内容仅在当次回调期间有效；若需在回调外保留，请拷贝相关字段。同一次回调中的 current/previous/next 与 from/to 视图彼此保持独立。保留显式的 previous/current/next 节点信息，缺失相邻节点时使用 null。cost 回调必须返回有限的非负数，否则适配器会抛出明确错误。当自定义代价不小于欧几里得距离时，Navcat 的距离启发式能给出最优路径；更低的自定义代价则继承 SDK 自身的启发式行为。

一个模块局部的原始重入标志使用 try/finally 包裹每次查询。在同步查询回调中发起嵌套查询、替换过滤器、替换网格、销毁或直接修改图结构均会抛出异常；在通过 SDK 使用另一个管理器之前，当前回调必须先结束。抛出异常的回调也会释放该标志，使管理器可再次被查询。该状态仅存在于按需启用的导航模块内部。

## 坐标转换

将 Lite 的 `(x,y,z)` 转换为 SDK 的 `[x,y,-z]`；对结果与法线执行相同的逆向操作。半包围尺寸为大小量，绝不取反。JSON 保持在 SDK 空间中。公共查询结果返回全新归属的向量/数组；回调视图则拥有上述较短的生命周期。输出中的负零可能会被归一化为零。

## 测试

测试内容涵盖：JSON 往返/替换失败原子性；畸形根节点；跨 await 修改调用方选项/向量；ID/ref 为 0 的情况；多个相互隔离的管理器；被过滤/无多边形以及部分路径；禁止嵌套查询/修改及异常后恢复；过期/外部 location 与被复用的连接 ID；挂起的可选导入与替换/销毁竞态；幂等拆解（清除内部引用且无 WebGPU 全局依赖）。
